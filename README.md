# homestead-lab

Дослідження: СЕС, будівництво власного домогосподарства та суміжні теми.

Відкритий репозиторій з нотатками, розрахунками та посиланнями на джерела.

## Структура

| Розділ | Про що |
|---|---|
| [`solar/`](solar/) | СЕС: потужність, обладнання, «зелений» тариф, підключення |
| [`building/`](building/) | Будівництво домогосподарства: ділянка, технології, кошториси |
| [`notes/`](notes/) | Загальні нотатки та посилання на джерела |
| [`templates/`](templates/) | Шаблони для нових нотаток |

## Як вести нотатки

- Одна тема — один файл у відповідному розділі, назва латиницею через дефіс (`inverter-choice.md`).
- Починайте з шаблону [`templates/note.md`](templates/note.md).
- Кожен висновок підкріплюйте джерелом і датою: ціни й тарифи швидко застарівають.
- Мова нотаток — українська.
