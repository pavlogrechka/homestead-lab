# Інструменти для планування

- `plan_solver.py` — розв'язувач обмежень (OR-Tools CP-SAT), який розкладає кімнати у внутрішній прямокутник будинку за мінімальними площами й розмірами, вимогою вікон для житлових кімнат і суміжністю з холом чи коридором. Запуск: `python3 plan_solver.py V4 240 corr` (конфігурація, секунди, `corr` або `nocorr`). Потрібен `pip install ortools`.
- `draw_plan.py` — малює SVG за JSON-результатом: стіни 0,40 м, перегородки, двері, вікна, шафа, тамбур, експлікація з перевіркою за ДБН. Запуск: `python3 draw_plan.py variant-A.json out.svg "Заголовок" "Підзаголовок"`.
- `variant-A.json`, `variant-B.json`, `variant-C.json` — готові розкладки (внутрішні розміри, м): x, y, ширина, глибина кожної кімнати.

Двері, вікна і шафа розміщуються автоматично й умовно. Сторона світу, освітленість і конструктивні питання не враховуються.

## Розстановка меблів у спальні

- `bedroom_search.py` — перебирає положення ліжка, столу й шафи вздовж стін кімнати 3,6 × H м (двері на західній стіні, вікно на східній), відкидає ті, де меблі перекривають зону дверей або вільні зони (проходи біля ліжка, фронт шафи, зона стільця), і перевіряє шлях від дверей шириною ≥ 0,6 м. Аргументи: `NS_W NS_D DESK_L DESK_D CHAIR WD_FRONT WD_LENS BED_W DOOR_DEPTH [H]`, наприклад `python3 bedroom_search.py 0.40 0.35 1.0 0.5 0.5 0.7 1.2,1.6 1.6 0.9`.
- `draw_bedroom.py` — малює SVG розкладки: `python3 draw_bedroom.py bedroom-layouts-door-in.json 0 out.svg "Заголовок" "Підзаголовок" in` (режим `in` або `out`).
- `bedroom-layouts-door-in.json`, `bedroom-layouts-door-out.json` — знайдені розкладки (м, у координатах кімнати).

## Загальний пошук меблів для будь-якої кімнати

- `room_furniture_search.py <config.json>` — те саме, що `bedroom_search.py`, але для довільних розмірів, стіни дверей, вікон і набору меблів. Приклад конфігурації — `master-bedroom-config.json` (кімната 3,3 × 3,8 м, двері на північній стіні, вікна на західній і південній). Видає до трьох найкращих розкладок на кожну стіну узголів'я.
- `draw_room.py <config.json> <layouts.json> <індекс> out.svg "Заголовок" "Підзаголовок"` — малює SVG розкладки з проходами.
- `master-bedroom-layouts.json` — знайдені розкладки великої спальні B2.
