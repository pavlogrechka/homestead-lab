# Інструменти для планування

- `plan_solver.py` — розв'язувач обмежень (OR-Tools CP-SAT), який розкладає кімнати у внутрішній прямокутник будинку за мінімальними площами й розмірами, вимогою вікон для житлових кімнат і суміжністю з холом чи коридором. Запуск: `python3 plan_solver.py V4 240 corr` (конфігурація, секунди, `corr` або `nocorr`). Потрібен `pip install ortools`.
- `draw_plan.py` — малює SVG за JSON-результатом: стіни 0,40 м, перегородки, двері, вікна, шафа, тамбур, експлікація з перевіркою за ДБН. Запуск: `python3 draw_plan.py variant-A.json out.svg "Заголовок" "Підзаголовок"`.
- `variant-A.json`, `variant-B.json`, `variant-C.json` — готові розкладки (внутрішні розміри, м): x, y, ширина, глибина кожної кімнати.

Двері, вікна і шафа розміщуються автоматично й умовно. Сторона світу, освітленість і конструктивні питання не враховуються.
